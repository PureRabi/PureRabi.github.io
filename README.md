# Academic homepage

Personal academic homepage based on [Academic Pages](https://github.com/academicpages/academicpages.github.io), with the original MIT license retained.

Source of the current customization: see `UPSTREAM.md`.

The site is a preliminary scaffold. English sections for biography, research, publications, and CV await the owner's details. No academic credentials have been inferred.

Read [Deployment and synchronization guide (Chinese)](docs/maintenance-zh.md) for first publication, software downloads, and Mac/Windows synchronization.

GitHub Actions builds the site on pushes to `master`. Set Settings → Pages → Source to GitHub Actions before the first deployment.
